## Headline (research-only · not GO)

- **Daily rebalance** (`xs_rank_ls_daily`) is the worst path: daily_path_DD **−23% / −16% / −37%**, unrecovered, **negative** total_ret_net in every window. Sticky’s lower turnover is not cosmetic.
- **MDH own-sign** is **not** a substitute for CS sticky: material daily DD and **negative** nets in 2020–22 and 2023–25.
- **Slow-rank CS** still prints **−14% / −11% / −22%** daily_path_DD. Not safer than sticky.
- **NEW** `xs_cs_dispersion_gate` (PIT trailing-median CS-dispersion gate) has **complete daily_path_DD** on all three windows (worst **−11.4%** in 2023–25). Smaller path DD than sticky in 2017–19, similar otherwise. **Research-only. Not main. Not GO.**
- Sticky remains **STABLE_RESEARCH_ONLY**. Path DD is **material** (worst window **−14.4%**, unrecovered). Period-net DD=0 must not be read as riskless.

> **Warning:** period-net DD = 0 when all period nets are positive is an **aggregation artifact**. It does **not** mean the strategy is riskless. Use **daily_path_DD** (duration / recovery / total_ret_net).

## Method

1. Load local `real_mirrors` bars for W98/W99 honest shards (2018/2020/2022/2024 absent — omitted, no synthetic fill).
2. Build the held book for each logic (CS ranks / MDH own-sign / dispersion gate).
3. Mark the book to market **daily** (equal-weight active names).
4. Subtract Python amortized daily cost drag while active (`one_way=10bp`).
5. Equity-curve peak-to-trough → max DD, duration, recovery, after-cost total return.
6. `evaluate_daily_path_dd_gate` must **complete**; period-net-only is **forbidden**.

Params are catalog base (or the new gate’s structural trailing-median rule) — **not** a retune. Codes: first 15 of `DEFAULT_EVAL_CODES`; max_days/shard=200.
