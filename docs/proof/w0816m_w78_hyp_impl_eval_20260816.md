### Formulas (not 1d simple daily sign)

**multi_day_hold**

```text
entry_t = sign(momentum_n)  with n = hold_days (default 5)
position = sticky fixed_horizon hold (rebalance every hold_days only)
R_hold   = close[t+hold_days] / close[t] - 1
gross    = mean(position_rebalance * R_hold)
net      = gross - one_way_cost / hold_days   # amortized cost
```

**macro_conditioned** (repo rate change mode — default)

```text
entry_t   = sign(momentum_n)
regime_t  = rate_up | rate_down | flat from Δ repo_rate (jsda_tokyo_repo_rates)
value_t   = entry_t if regime allows:
              rate_down → long_only (+1 kept)
              rate_up   → short_only (−1 kept)
              flat / gap → no trade (None; no invent fill)
gross     = mean(value * R_{t→t+1}) on active days
net       = gross - one_way_cost (10bp)
```

**repo_rate_change** feature (candidate)

```text
delta = rate[latest as_of_date] - rate[as_of_date lookback steps earlier]
```

Dataset: `jsda_tokyo_repo_rates` only. Status **candidate** (promote only after feature-level E2E; pure helper unit-tested).
